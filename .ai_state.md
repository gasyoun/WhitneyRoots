## 🧠 Dev Notes & Hypotheses

**Grammar transliteration**: The Grammar PDF uses `ç` (c-cedilla U+00E7) for
IAST `ś`. The builder normalises with `to_grammar_conv(root)`. All other IAST
diacritics match directly. Confirmed by search counts (ç:2665 vs ś:2 in text).

**Chapter ranges**: Whitney's own chapter numbering (I–IX) differs from Hindu
gaṇa numbers (1–10). The builder uses Hindu numbers matching `app_data.json`.
Accurate char-position boundaries for each class chapter verified against the
actual chapter-header text.

**Key Section A decisions** (Grammar is highest authority):
- `mṛ` (ids 571, 572): Keep class I. §731 = mṛṇá á-stem (class I). §773 says
  mriyáte is a PASSIVE (yá-class), not class IV. Whitney's I is correct.
- `vadh` (id 705): Keep class I (nominal). Defective root: present supplied by
  √han. Grammar §904a (aorist avadhi), §1042g (denominative). Class I from Roots.
- `cūṣ` (id 234): Keep class IV. §240b is phonological only. No Grammar
  class-chapter confirmation found; class IV from Whitney Roots book.

**DCS corpus limitation**: DCS `lemma.grammar` is itself a lexicon metadata field
(not derived from attested forms). It reflects Böhtlingk/MW tradition, not Whitney.
For corpus-level class verification, use `token` table present-tense forms directly.

**§731 context**: Falls in nā-class chapter (§717–733) because Whitney discusses
transfers from the nasal/nā domain to the á-class (class I). The citation is
correct: §731 explicitly assigns mṛ a class-I stem form (mṛṇá).
