## 🧠 Dev Notes & Hypotheses

**⚠️ Critical methodology finding (the I/VI accent collapse).** The DCS corpus is **unaccented**.
Class I (`cárati`, guṇa root + accent on root) and class VI (`tudáti`, weak root + accent on `-á`)
have identical surface present-stems without accent. The verification script's patterns for I and
VI both match `root+a`, so it returned "I, VI" for nearly every thematic root, and the addition
step "completed the pair." This produced 117 spurious additions — **reverted**. The only reliable
non-accent tell is **root-vowel grade** where guṇa would change it (`viśáti` keeps `i` ⇒ VI; a
class-I form would raise it). Where guṇa changes nothing (`car`, `nam`), the corpus is silent.
Same trap for **IV vs passive** (both `root+ya`): `jñāyate`/`dhriyáte` are passives, not class IV.

**Short-root text contamination.** In `src/wg_text.txt`, root `as` matches the English word "as"
2482× (11× inside the VI chapter alone), `i` 598×. Auto `specific`/`exception` tags on short roots
can be false (Queue D).

**Grammar transliteration**: PDF uses `ç` (U+00E7) for IAST `ś`; builder normalises via
`to_grammar_conv(root)`. Confirmed by counts (ç:2665 vs ś:2).

**Chapter ranges**: Whitney's chapter numbering (I–IX) ≠ Hindu gaṇa (1–10). Builder uses Hindu
numbers matching `app_data.json`; char-position boundaries verified against chapter headers.

**Key Section A decisions** (Grammar is highest authority):
- `mṛ` (571/572): keep I. §731 = `mṛṇá` á-stem (I); §773 `mriyáte` is PASSIVE, not IV.
- `vadh` (705): keep I (nominal). Defective; present supplied by √han. §904a aorist, §1042g denom.
- `cūṣ` (234): keep IV. §240b phonological only; IV is from Whitney Roots.

**DCS `lemma.grammar` is itself lexicon metadata** (Böhtlingk/MW tradition), not attested-form
evidence. A disagreement there is lexicon-vs-lexicon, never corpus proof.
